# 🐍 Python Mini Systems

Colección de mini sistemas desarrollados en **Python** con el objetivo de fortalecer la lógica de programación, la programación modular y las buenas prácticas de desarrollo.

Este repositorio reúne proyectos pequeños pero completos, enfocados en resolver problemas reales mediante aplicaciones de consola.

---

# 🎯 Objetivos

- Practicar programación orientada a problemas.
- Mejorar la lógica de programación.
- Aplicar programación modular.
- Escribir código limpio y organizado.
- Utilizar estructuras de datos de Python.
- Implementar validaciones y menús interactivos.
- Preparar una base sólida para proyectos más grandes.

# ▶️ Cómo ejecutar un proyecto

1. Clona el repositorio.

```bash
git clone https://github.com/TU_USUARIO/python-mini-systems.git
```

2. Entra al proyecto que deseas ejecutar.

```bash
cd python-mini-systems/sistema-biblioteca
```

3. Ejecuta el archivo principal.

```bash
python main.py
```
